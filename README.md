# Derelict Blade

A top-down action-adventure set on a derelict cyberpunk space station, where ancient swords meet future technology. Built in phases, mostly by AI, with a human director.

## Start here

The design lives in `docs/`:

| File | Contents |
| --- | --- |
| `docs/00-game-plan.md` | Overview: vision, story, gameplay, content map, stack, pipeline, roadmap, risks |
| `docs/01-build-phases.md` | Phase-by-phase tasks, Go prompts, acceptance checks |
| `docs/02-technical-spec.md` | Every system, number and schema |
| `docs/03-narrative-bible.md` | Theme, backstory, characters, beats, endings, writing rules |
| `docs/04-lore-logs.md` | Full text of all 34 lore logs |
| `docs/05-art-audio-bible.md` | Palette, prompts, sprite lists, lighting, music, SFX |

To build: open a coding agent on this repo and paste the Phase 0 Go prompt from `docs/01-build-phases.md`.
